# Lilly Medical Aesthetics — Website (v1)

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · Motion · Lucide. No database.

## Configure (Vercel → Project → Settings → Environment Variables)
See `.env.example`. Contact details, WhatsApp, map and Navitas booking link stay as
"to be confirmed" placeholders until the matching variable is set — no code change needed.

## Content
- Services: `lib/services.ts` · Blog: `lib/blog.ts` · Site settings: `lib/site.ts`
- Doctor photo: `public/images/dr-skhosana.webp` · Logo: `public/logo.svg`, `public/lotus.svg`

## Develop
npm install && npm run dev
